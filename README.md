# Enterprise Database Management System

This repository contains the Enterprise Database Management System.

## Project Structure

```
.
└── version 1/
    ├── client/    # React (Vite) Frontend Application
    └── server/    # Node.js Express Backend with SQLite (sql.js)
```

## Getting Started

### Backend (Server)

```bash
cd "version 1/server"
npm install
npm run dev
```

### Frontend (Client)

```bash
cd "version 1/client"
npm install
npm run dev
```
